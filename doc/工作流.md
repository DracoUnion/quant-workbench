## 四、公共护栏与落地顺序

**公共护栏**：  
1. 所有数据标来源；信息不足标盲区，禁止编造。  
2. 交易类输出必须“仅供参考，不构成投资建议”，并保留人工确认。  
3. 合规红线：保本保收益、稳赚不赔、内幕消息直接红灯。  
4. 低可信源熔断：可信度<0.3终止流程。  
5. 交易安全：频率/浮亏/极端波动三重熔断；随机延迟与数量价格微调仅用于稳健执行，不改变交易意图。  
6. 知识库入库、合规放行、KYC高风险、策略上线均需人工闸门。

**推荐落地顺序**：  
W0 底座 → W8 合规安全 + W4 组合监控 → W9 办公自动化 → W2 投研 + W1 宏观配置 → W5 短线 + W6 事件信号 → W7 客户经营 + W3 回测评审。
